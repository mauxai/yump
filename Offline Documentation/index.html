Install in Minutes

No config-file surgery. Set one URL, build, and open the site — the built-in web installer walks you through the rest.

  • ①Set NEXT_PUBLIC_APP_URL in .env.production
  • ②Run npm install and npm run build
  • ③Start the server — every URL redirects to /install
  • ④Walk the 4-step wizard: requirements → database → license → admin

Solution Overview

One Next.js application serving three surfaces — the user app, the admin panel, and a documented REST API.

Surface Path Focus
User App / AI editor, projects, gallery, billing, notifications
Admin Panel /admin Users, plans, AI models, effects, templates, settings
REST API /api/v1 JWT-authenticated API with OpenAPI docs
Mobile App Flutter Android & iOS companion app on the same backend

Everything runs from a single Node.js process backed by MySQL — deployable with npm run start or the bundled PM2 ecosystem file.

Quick Setup Reference

Follow these steps in order to get 6amStudio running on your server:

  1. Prepare the server Node.js 18+, MySQL, and a reverse proxy (Nginx or Apache) pointing at port 3000. Server Requirements →
  2. Configure, build, and start Set NEXT_PUBLIC_APP_URL to your domain, then npm install, npm run build, and start with PM2 or npm run start. Quick Start →
  3. Run the install wizard Open your domain — the wizard checks requirements, connects the database, activates your purchase code, and creates the super admin. Installation Process →
  4. Configure the platform Log in at /admin to add AI model API keys, SMTP, payment gateways, plans, and branding. Configuration →
